# Emotion Detection System

A real-time facial emotion detection project using Python and OpenCV.

## Technologies
- Python 3.13
- OpenCV
- NumPy
- Matplotlib
- TensorFlow (optional model dependency)

## Run
Activate the virtual environment and execute:

python emotion_detector.py

## Controls
- 1-7: Emotion
- 0: Clear
- T: Threshold
- R: Reset
- S: Save
- Q: Quit
